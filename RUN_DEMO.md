# Quick demo

The repository includes a small demo LightGBM artifact so the Flask interface can be shown without downloading the full KASANDR dataset.

```bash
pip install -r requirements.txt
python app/app.py
```

Open `http://127.0.0.1:5000`.

**Important:** the included demo model is trained on generated data. For interview claims about real-world model performance, download KASANDR and run the three notebooks to create the real model.
