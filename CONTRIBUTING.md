# Contributing

Thanks for considering a contribution!

## Before opening an issue

- Search existing issues first.
- Explain the problem clearly.
- Include the notebook, cell or Flask page involved when possible.

## Pull requests

1. Fork the repository.
2. Create a focused branch.
3. Keep notebooks readable and remove unnecessary output.
4. Do not commit the original large dataset or generated model files.
5. Add a short explanation of your change.
6. Test the Flask app locally if your change touches `app/`.

## Good contribution ideas

- better leakage-safe CTR features
- calibration analysis
- improved model monitoring
- additional evaluation metrics
- cleaner UI/UX
- Docker deployment
- tests for feature transformations

Please keep the project educational, reproducible and easy for a student/interviewer to understand.
